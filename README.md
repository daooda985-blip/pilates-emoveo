# Pilates by emoveo

Локально работающий прототип планировщика занятий Pilates. Текущая версия размещается как статический сайт на GitHub Pages и **не подключена к облачной базе данных или серверной авторизации**.

## Структура проекта

- `index.html` — интерфейс приложения, формы, отображение и редактирование планов.
- `js/generator.v1.js` — генератор занятий, распределение времени и проверка плана.
- `js/storage.local.v1.js` — адаптер локального хранилища браузера.
- `data/exercise-library.v1.json` — библиотека карточек упражнений.

## Возможности текущей версии

- Выбор длительности занятия, уровня группы, фокуса и оборудования.
- Формирование трёх этапов: разминка, основной комплекс, завершение и растяжка.
- Ориентировочное распределение активного времени 25% / 50% / 25%.
- Две паузы по 15 секунд учитываются в общей длительности занятия; переходы по 5–10 секунд в расчёт не включаются.
- Редактирование плана: изменение порядка, замена, добавление и удаление упражнений.
- Фильтрация библиотеки по названию, этапу и направлению.
- Локальная история занятий, шаблоны и настройки.
- Экспорт и импорт настроек, истории и шаблонов в JSON.

## Хранение данных и ограничения

- Настройки, история и шаблоны сохраняются в `localStorage` текущего браузера.
- Данные не синхронизируются между устройствами и не отправляются в облако.
- Серверная авторизация, роли пользователей, совместная работа студии и изоляция данных разных студий пока не реализованы.
- Разделы «Клиенты и группы» и «Расписание» пока являются заглушками.
- Генератор использует редакционно подготовленные карточки и ориентировочные оценки активного времени. Если библиотека не позволяет заполнить этап, приложение должно явно показать дефицит — не следует искусственно увеличивать дозировку.
- Видеодемонстрации упражнений требуют отдельной проверки точных источников.
- План является рабочим черновиком, а не медицинской рекомендацией. Инструктор проверяет пригодность движений для конкретной группы и учитывает ограничения участников.

## Запуск и публикация через GitHub Pages

Для работы сайта должны быть опубликованы **все перечисленные файлы и папки** с сохранением структуры путей. Одной загрузки `index.html` недостаточно: генератор, локальное хранилище и JSON-библиотека подключаются отдельно.

После публикации проверьте:
1. загрузку библиотеки упражнений;
2. генерацию занятий на 30, 45, 60, 75 и 90 минут;
3. предупреждения о незаполненных этапах;
4. сохранение истории и шаблонов;
5. экспорт и импорт резервной копии.

Перед использованием реальных данных клиентов потребуется отдельная серверная архитектура, аутентификация, разграничение доступа, политика обработки данных и проверка требований законодательства.
