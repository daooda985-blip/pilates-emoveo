# Pilates by emoveo — интерактивный планировщик

Первая версия статического сайта с интерактивным черновиком занятия.

## Файлы
- `index.html` — весь сайт: структура, стили и JavaScript планировщика.

## Что умеет планировщик
- Выбирать продолжительность, уровень группы, фокус и оборудование.
- Формировать структуру из трёх этапов: разминка, основной комплекс, растяжка всего тела.
- Предлагать ориентировочное распределение времени 25% / 50% / 25%.
- Копировать получившийся черновик.

Результат формируется в браузере и не сохраняется автоматически. Это общий шаблон, не медицинская рекомендация. Инструктор должен адаптировать план под группу и учитывать сообщённые ограничения.

## Обновление GitHub Pages
Загрузите `index.html` в корень ветки `main` репозитория `pilates-emoveo`, подтвердив замену существующего файла. Дождитесь обновления GitHub Pages и обновите сайт в браузере.
