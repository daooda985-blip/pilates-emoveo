# Аудит текущего состояния Pilates by emoveo

Дата проверки: 31 октября 2026  
Назначение: зафиксировать фактическое состояние перед созданием общей оболочки. Это аудит кода, не полный браузерный QA.

## 1. Что уже существует

- `index.html` — основная публичная страница, содержит HTML, встроенные CSS-стили и большую часть интерфейсного JavaScript.
- `js/generator.v1.js` — отдельный модуль генерации и проверки плана.
- `data/exercise-library.v1.json` — каталог из 40 упражнений.
- Планировщик имеет поля продолжительности, уровня, основного фокуса и оборудования.
- Генератор формирует три этапа: разминка, основной комплекс и растяжка.
- В черновике есть редактирование порядка, замена, добавление и удаление упражнений.
- Есть копирование текстового плана.
- В карточках отображаются техника, дозировка, дыхание, варианты упрощения/усложнения и меры предосторожности.
- Упражнения могут содержать ссылку на демонстрацию; для непроверенных видео отображается соответствующая отметка.

## 2. Что пока отсутствует или ограничено

- Нет отдельной рабочей панели Dashboard.
- Навигация пока ведёт только к маркетинговым секциям страницы.
- Нет отдельной страницы или полноценного интерфейса каталога упражнений.
- Нет сохранения занятий между перезагрузками страницы.
- Нет пользовательских шаблонов и экрана управления ими.
- Нет отдельного раздела настроек приложения.
- Нет профилей клиентов, групп, расписания и аналитики.
- Основной CSS и большая часть UI-логики находятся внутри `index.html`; это увеличивает сложность дальнейшего развития.
- Генератор и каталог уже разделены по файлам, но остальные границы модулей ещё не оформлены.

## 3. Что важно сохранить

- Существующий планировщик и его поля.
- Генерацию трёх обязательных этапов.
- Проверки времени, уровня и оборудования.
- Редактирование упражнений.
- Копирование плана.
- Существующую библиотеку и её метаданные.
- Явное отображение дефицита времени вместо искусственного увеличения дозировки.

## 4. Рекомендуемый порядок изменений

1. Создать общую навигацию и рабочую оболочку, не переписывая генератор.
2. Добавить Dashboard и понятные входы в существующий Planner.
3. Добавить базовый экран Exercise Library поверх существующего JSON-каталога.
4. Добавить каркасы Templates, Clients, Schedule, History и Settings с честными статусами «в разработке».
5. Вынести стили и интерфейсные модули постепенно, после проверки каждого шага.
6. Затем внедрить local-first хранение, экспорт и импорт данных.

## 5. Ограничения аудита

Проверены исходники и структура данных, но этот аудит сам по себе не подтверждает полное тестирование в браузере, на мобильном устройстве или после публикации GitHub Pages. Такие проверки выполняются отдельно после внесения изменений.
