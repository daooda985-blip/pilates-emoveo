# Структура модулей Pilates by emoveo

Каталоги модулей будут добавляться по мере реализации. На текущем этапе это карта разделения ответственности, а не набор готовых функций.

- dashboard — главная рабочая панель.
- planner — создание и редактирование занятий.
- library — каталог упражнений.
- templates — шаблоны комплексов.
- clients — клиенты и группы (будущий модуль).
- schedule — расписание (будущий модуль).
- history — история и аналитика (будущий модуль).
- settings — настройки и управление локальными данными.

Существующий генератор и библиотека остаются в текущих путях до отдельного этапа безопасного переноса.
