# Pilates by emoveo

Первая статическая версия сайта Pilates — помощника для инструкторов.

## Файлы
- `index.html` — структура и текст сайта.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — небольшие интерактивные элементы.

## Как посмотреть сайт
Откройте `index.html` в современном браузере.

## Перед публичным запуском
- Замените демонстрационный адрес `hello@example.com` в `index.html` на настоящий контактный адрес или удалите ссылку.
- Проверьте описание и все тексты.
- Добавьте настоящие страницы политики конфиденциальности и условий использования, если они нужны для выбранных функций.
- Не размещайте пароли, API-ключи или персональные данные клиентов в репозитории.

## Публикация через GitHub Pages
В репозитории откройте **Settings → Pages**. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните. После публикации GitHub покажет адрес сайта в этом разделе.
